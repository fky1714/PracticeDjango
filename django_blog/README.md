# Django 学習用ブログアプリケーション

これは、Djangoの基本的な機能を学ぶために作成されたシンプルなブログアプリケーションです。

## 概要

このプロジェクトは、Django初学者がCRUD（作成、読み取り、更新、削除）操作、MTV（モデル、テンプレート、ビュー）アーキテクチャ、フォーム、管理サイトなどの基本的な概念を理解することを目的としています。

コードの主要な部分には日本語で解説コメントが付けられており、処理の流れを追いやすくなっています。

## 機能一覧

*   **投稿の一覧表示 (Read)**
    *   トップページで全ての投稿をページネーション付きで一覧表示します。
*   **投稿の詳細表示 (Read)**
    *   各投稿の個別ページを表示します。
*   **新規投稿の作成 (Create)**
    *   新しいブログ記事を作成し、データベースに保存します。
*   **投稿の編集 (Update)**
    *   既存の投稿を編集し、更新します。
*   **投稿の削除 (Delete)**
    *   投稿をデータベースから削除します。
*   **管理サイト**
    *   Djangoが提供する高機能な管理サイトから、投稿データを直接操作できます。

## 必要なもの

*   Python (3.8以上を推奨)
*   pip (Pythonのパッケージ管理ツール)

## 環境構築と実行の手順

1.  **リポジトリをクローンまたはダウンロードします**
    ```bash
    git clone <repository_url>
    cd django_blog
    ```

2.  **仮想環境を作成して有効化します（推奨）**
    ```bash
    # Windowsの場合
    python -m venv venv
    venv\Scripts\activate

    # macOS / Linuxの場合
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **必要なパッケージをインストールします**
    プロジェクトには `requirements.txt` が含まれています。以下のコマンドで、必要なライブラリ（Django）をインストールします。
    ```bash
    pip install -r requirements.txt
    ```
    もし `requirements.txt` がない場合は、直接Djangoをインストールしてください。
    ```bash
    pip install Django
    ```

4.  **データベースを初期化します**
    `migrate` コマンドを実行して、データベースにテーブルを作成します。
    ```bash
    python manage.py migrate
    ```

5.  **開発用サーバーを起動します**
    ```bash
    python manage.py runserver
    ```

6.  **ブラウザで確認します**
    ウェブブラウザを開き、 `http://127.0.0.1:8000/` にアクセスしてください。ブログの一覧ページが表示されます。

## 管理サイトへのアクセス

このプロジェクトには、投稿データを管理するための管理サイトが設定されています。

1.  **スーパーユーザー（管理者アカウント）を作成します**
    ```bash
    python manage.py createsuperuser
    ```
    コマンドの指示に従い、ユーザー名、メールアドレス、パスワードを設定してください。

2.  **管理サイトにアクセスします**
    ウェブブラウザで `http://127.0.0.1:8000/admin/` にアクセスし、先ほど作成したスーパーユーザーの情報でログインします。

    ログイン後、「Posts」セクションからブログ投稿の追加、編集、削除が可能です。
